## O QUE MUDOU

### 1. A divergência 62 vs 48 foi explicada, não apagada

A missão `C-RECONCILE-SYSTEM-MAP-AS-OBSERVABILITY-SYSTEM-V1` re-mediu o mapa e mostrou que os números 62 e 48 vinham de árvores diferentes e de lentes diferentes. No HEAD da reconciliação, o universo visual medido passou a ser:

```text

TOTAL VISUAL = 65
PENTE FINO INCLUDED = 48
PENTE FINO EXCLUDED = 17
65 = 48 + 17
```

A consequência durável não é “os números agora batem”. É:

```text
TODA CONTAGEM PUBLICADA PRECISA DECLARAR UNIVERSO, MEMBROS, REGRA E FRESCURA.
UMA LENTE PODE FILTRAR; NUNCA PODE PERDER SILENCIOSAMENTE.
```

### 2. O System Map precisa ser tratado como instrumento de evidência, não como desenho

Decisão de direção desta rodada:

```text
SYSTEM MAP OBSERVA A MÁQUINA.
SYSTEM MAP NÃO DEFINE A ARQUITETURA.
O FRONTEND É UMA PROJEÇÃO DE EVIDÊNCIAS, NÃO A FONTE DA VERDADE.
```

O mapa confiável precisa separar pelo menos quatro planos:

```text
DECLARED
CODE
OBSERVED
PROVEN
```

Sem promoção automática entre eles:

```text
DECLARED != CODE
CODE != OBSERVED
OBSERVED != PROVEN
```

Isto formaliza leis já maduras do SINTONIA:

```text
CAN DO != DID DO
MODULE EXISTS != EDGE EXISTS != FLOW EXISTS
DECLARED EDGE != OBSERVED EDGE
UNKNOWN != NO
STALE != CURRENT
```

### 4. Defeitos estruturais provados no System Map

A reconciliação encontrou e deixou sem maquiagem:

1. **Pente fino um ciclo atrás.** `pente_fino_da_coleta.py` lê `state.generated.json` antes de `generate_system_map.py` escrever o estado novo. Em mudança de universo, a primeira corrida mede a árvore anterior.
2. **Duas cadeias de geração.** `CADEIA-DO-MAPA.json` declara 7 passos; o workflow executa scripts adicionais fora desse owner. Duas listas canônicas viram duas cadeias.
3. **Filtro estático por território divide a mesma espécie.** Cards `nivel=PRINCIPAL` podem entrar ou ficar fora do pente fino apenas porque o território está ou não numa tupla.
4. **Exclusões sem decisão semântica.** Onze cards em `Z-MEDIDAS` e `C-READY` ficaram `UNKNOWN`: saem por mecânica de filtro, não por uma lei escrita dizendo que não pertencem ao pente fino.
5. **Nome visual não é identidade.** Há dois territórios com o mesmo nome “A SALA DE ESPERA”. Nome não pode ser usado como identidade ou pertença.
6. **Topologia sem artefato persistente.** `censo_da_topologia.py` produz número observável no terminal, mas não deixa owner persistente reproduzível para esse veredito.
7. **Drift incompletamente coberto.** Nem todos os censos críticos participam hoje do mesmo mecanismo de frescura/provenance.
8. **“Card” possui múltiplas espécies.** Architecture node, visual card, portal tool e measurement artifact não podem compartilhar contagem sem qualificar a espécie.

## COMO O MAPA DEVE GANHAR CONFIANÇA

Princípios já aprovados para o desenho do contrato:

### Entidades

Toda entidade precisa de identidade canônica independente de nome visual, posição, território ou família.

### Arestas

Uma seta precisa ter semântica e evidência. Não existe “edge verde” genérico. Relações como `CALLS`, `READS`, `WRITES`, `PRODUCES`, `DERIVES`, `PERSISTS`, `ADMITS`, `CONSUMES`, `IMPORTS`, `TESTS` e `PROVES` só podem existir se o sistema medir que são espécies reais.

Cada edge deve poder portar estados independentes:

```text
DECLARED
CODE
OBSERVED
PROVEN
```

### Evidência

Toda afirmação relevante publicada deve conseguir responder:

```text
WHAT ASSERTION?
WHICH EVIDENCE?
WHO OWNS IT?
MEASURED WHEN?
FROM WHICH TREE?
FROM WHICH RUN / ENVIRONMENT, WHEN APPLICABLE?
CURRENT, STALE OR UNKNOWN?
```

### Runtime

Scanner de código pode provar `CODE`; não pode sozinho provar `OBSERVED`.

Runtime precisa virar cidadão de primeira classe do mapa, com RUN, input/output, stage, result, observed_at e versão/fingerprint quando conhecidos.

### Lentes

Toda lente deve declarar:

```text
LENS_ID
PARENT_UNIVERSE
FILTER_RULE
MEMBERS
COUNT
EXCLUDED_MEMBERS
EXCLUSION_REASON
FRESHNESS
```

E quando for subconjunto:

```text
PARENT = INCLUDED + EXCLUDED
```

### Trust

O futuro contrato deve distinguir:

```text
MAP TRUST != COLLECTION HEALTH != SYSTEM HEALTH
```

Um mapa confiável pode mostrar a Collection vermelha. Isso é sucesso do mapa.

Estados candidatos a formalizar:

```text
PASS
DEGRADED
FAIL
UNKNOWN
```

Sem afrouxar para “ficar verde”.
