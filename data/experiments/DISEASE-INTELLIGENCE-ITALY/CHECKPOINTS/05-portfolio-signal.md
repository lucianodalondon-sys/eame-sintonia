# CHECKPOINT — THE ADAMA-RELEVANT SIGNAL THAT IS ACTUALLY PROVED

`var 49 prodotto_principale` records **the active ingredient actually applied**, per
vineyard, per visit. It had not been analysed. It is the strongest ADAMA-relevant finding of
this work, and — unlike everything in the horizon curve — it depends on no predictive claim.

## What is there

**21,911 recorded applications, 2006–2026**, naming the active substance.

| all-time | applications |
|---|---|
| **Prodotti rameici (copper)** | **15,548** |
| Dimetomorf (CAA) | 1,633 |
| Cimoxanil | 1,070 |
| Fosetil-Al | 816 |
| Iprovalicarb (CAA) | 435 |
| Fluopicolide | 315 |
| Metalaxyl-M | 282 |
| zoxamide | 279 |
| Folpet | 206 |

The recorded palette widens from **6–7 distinct actives (2006–2008) to 22–23 (2020s)**.

## Copper's share is rising, and the trend is real

| | |
|---|---|
| 2006 | 70.6 % copper |
| 2026 | **80.5 % copper** |
| ρ(year, copper share) | **+0.780** |

**Tested as an artefact and it is not one.** Recording completeness varies a lot between
seasons (35.6 %–83.6 % of visits carry a product), so the trend could have been an artefact
of who filled the form. It is not: ρ(recording rate, copper share) = **−0.275** — weak, and
in the *wrong* direction to explain the rise.

**Confirmed independently by defence regime**, which is the decisive check:

| regime | mean copper share |
|---|---|
| `bio` | **0.962** |
| `integrato` | 0.605 |
| `integrato_volontario` | 0.636 |

Organic vineyards run at ~96 % copper, integrated at ~60 %, every season 2020–2026. That is
exactly what the variable should show if it means what it says, and it is strong evidence
the field is real rather than noise.

## What this is, and what it is not

**It is** a 20-season, per-vineyard, dated record of what Tuscan growers actually applied
against downy mildew, with the regime attached — a genuine market-structure signal, and the
one place where a portfolio conversation can rest on observation.

**It is NOT market share.** These are applications *recorded in a monitoring network*, not
sales, not hectares, not a census. The recording rate varies between 35.6 % and 83.6 % by
season, so it is a sample of unknown representativeness.

**And the ADAMA link is still not proved.** Naming an active substance is not the same as
matching it to an ADAMA Italy registration. That cross needs the actual Italian portfolio,
which this pilot does not have:

```
ADAMA_PRODUCT_RELATION = UNKNOWN — no verified Italian portfolio list was used
CROP_MATCH             = PLAUSIBLE_NOT_PROVED (vite is a major ADAMA crop)
TARGET_MATCH           = PLAUSIBLE_NOT_PROVED (peronospora is a major target)
TIMING_MATCH           = NOT_ASSESSED
```

A lexical match between an active substance here and a product name elsewhere would **not**
be proof, and the mission forbids treating it as such. Establishing the relation requires the
registered Italian portfolio as an input.
