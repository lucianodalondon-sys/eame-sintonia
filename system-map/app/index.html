Começa com DADO e COMANDO ligados: é o caminho que a coleta percorre. Ligue as outras para auditar — nada é escondido, só recolhido. Nenhum cartão desaparece; só as setas.

Prova da ligação

A seta sem prova é cinzenta, tracejada e leva um anel no meio — três sinais, para o estado não depender só da cor. Hoje são …, e o «mostrar caminho completo» não atravessa nenhuma delas: seguir uma ligação não provada transformaria «talvez» em «portanto».

A língua das setas
DADO linha grossa — um item sai mesmo daqui e entra ali
COMANDO tracejado largo — esta peça manda a outra executar
ESCRITA linha média — guarda o resultado num lugar
LEITURA pontilhado — lê um ficheiro que a outra escreveu
REGRA traço-ponto — consulta uma lei para decidir
PROVA pontilhado fino — um teste observa a outra peça
CÓDIGO pontilhado mínimo — só dependência; nada passa aqui

A categoria diz sobre o quê é a ligação; a prova, acima, diz se ela aconteceu. São eixos diferentes: uma seta de comando pode estar por provar, e uma de dado pode estar observada. Uma travessia OBSERVADA é a única linha cheia e escura do mapa — análise estática prova CAN DO; só a corrida prova DID DO.

Cinzenta porque ali nada é transformado — só guardado. No fim, separada da esteira, fica a GOVERNANÇA: o que mede e o que regula os outros, sem ser um passo de nenhum deles.
