# REAL contra DEMO — o resumo que evita adivinhação

**Objetos com ID no pacote: 3773.**

| classe de proveniência | objetos | o que significa para a tela |
|---|---:|---|
| `REAL_FACT` | 1955 | pode ir para a tela como fato, com a fonte ao lado |
| `REAL_SOURCE` | 1225 | pode ir para a tela citando a fonte e a data |
| `REAL_DERIVED` | 593 | precisa do rótulo «interpretação do Sintonia» visível |
| `SYNTHETIC_DEMO` | 0 | — |
| `INTERNAL_DATA_REQUIRED` | 0 | mostrar como «dado interno não conectado» |

---

## A regra de tela, em uma linha por classe

- **`REAL_FACT`** — o rótulo, o ato, o decreto. Vai como está, com fonte e data.
- **`REAL_SOURCE`** — o anúncio, o vídeo, o comentário, o boletim. Vai com fonte, data **e** com o que ele não prova.
- **`REAL_DERIVED`** — o par cultura×alvo, a temperatura de mercado, a distância entre menção e linha de uso. **Nunca** vai sem o «por quê» aberto ao lado.

⚠️ Um objeto `REAL_DERIVED` apresentado sem o «por quê» vira caixa-preta — e caixa-preta é exatamente o que este projeto existe para não ser.
